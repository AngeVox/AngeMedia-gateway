# 作品库分页与统计合同

`GET /v1/assets` 继续要求管理员登录，默认 `limit=100`、`offset=0`，上限500。原 `data` 数组及单项安全字段不变；新增字段供完整作品库分页使用。

可选查询：

| 参数 | 规则 |
| --- | --- |
| `media_type` | `image` 或 `video` |
| `source` | `generated` 或 `upload` |
| `job_id` | 精确匹配任务编号 |
| `limit` | 1–500 |
| `offset` | 非负整数 |

未提供的条件不筛选；多个条件同时匹配。类型或来源的空字符串/未知值返回422，前端无条件时省略参数。`job_id` 沿原不透明编号合同，值不会拼进SQL。

响应增加：

| 字段 | 含义 |
| --- | --- |
| `total` | 当前全部筛选条件下的记录总数 |
| `summary.total` | 与 `total` 相同 |
| `summary.image` / `summary.video` | 同一匹配范围的图片/视频数量 |
| `summary.size_bytes` | 同一范围的记录字节数之和，不是磁盘用量 |
| `limit` / `offset` | 本次请求的分页参数 |

时间倒序、编号倒序构成稳定顺序。页越界仍返回空 `data` 和准确总数，不暗改旧接口的offset语义。

列表、聚合及关联任务/生成记录来自一个读事务快照。关联摘要批量读取，继续原whitelist、脱敏与受控链接投影；无关联任务的上传作品仍可列出。此接口不执行生成、外部查询或费用操作。

Web每次只加载当前页，类型/来源/任务筛选和统计都由服务端处理；清除任务筛选保留其他条件。容量随原两行布局改变，重新请求原首项所在页。库存缩减使页越界时最多补查一次，持续变化则显示可刷新的错误；迟到或离页响应不能覆盖当前内容。旧服务端没有新增分页字段时不回退成“前100条即全库”。

一次响应内部一致；不同翻页请求之间不锁定长期快照。新增/删除可能移动偏移位置，刷新后以当前库存为准。
