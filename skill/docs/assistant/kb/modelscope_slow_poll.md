# ModelScope Slow Poll Runbook

ModelScope异步图片任务长时间未完成，不代表上游已经失败。先查看同一条任务的阶段、已观察状态和错误分类，不因短时间没有结果就再生成一条。

新任务包含async_image v1标记时，image_generate负责首次生成选择，image_poll只查询已受理编号，image_import取回并保存作品。查询429/网络异常只重试查询；下载失败只重试保存，不重新生成。成功作品已落库后，私有输出定位会清除，来源和任务号仍保留。

只有服务方明确返回FAILED，才记录上游失败。image_poll_timeout和image_import_timeout表示本地等待已结束，不能据此声称服务方失败或已经退款。提交超时、5xx或没有明确编号时保持未确认，不自动重提或换渠道。

Key、端点或代理变化时，后台等待原配置恢复后取回，不用新配置冒充原账户；已受理任务不再依赖输入参考图。若本地已结束等待，迟到的受理编号只补事实，不自动复活终态。需要管理员核对原任务时，不要编造当前不存在的恢复按钮或外部查询工具。

旧载荷不自动补来源收据。ModelScope魔粒余额、账户绑定/实名、型号权限与本地提交预算分开判断；大量任务变慢时结合明确429/5xx与渠道状态排查，不能只提高并发。真实账户与图像质量仍需单独验证。
